# CREDITS - SuperIntelligent Cat (GZDoom mod)

Everything in this mod is either generated for it, made for it, or reused under a licence that allows it.
No file comes from Minecraft, Mojang, Doom or any other commercial game.

## Code
- All ZScript (mod/zscript/), the texture table (mod/mctexmap.txt, mod/mckeys.txt), ANIMDEFS, SNDINFO, TRNSLATE, MAPINFO: written for this mod.

## Creatures, the Cat, effects (mod/sprites/)
- SuperIntelligent Cat (SCAT*), creeper (CREP*), zombie (MCZB*), skeleton (MCSK*), spider (MCSP*), ghast (MCGH*), enderman (MCEN*):
  generated for this mod with fal.ai (FLUX.2 [dev] text-to-image and FLUX.2 edit; a few frames with ByteDance Seedream v4 edit),
  then cut out, cleaned and fitted with the kit tools. Some frames are derived by editing generated frames (mirrored legs, swell and flash tints).
- Effects (MCPF smoke, MCFL flash, MCXP experience orb, MCAN anvil, MCAR arrow, MCFB fireball): generated with fal.ai FLUX.2 for this mod.
- Prompts, seeds and request ids: gen/fal_manifest.jsonl.

## First-person weapons, weapon pickups and hotbar icons (MSWD, MPCK, MBOW, MXBW, MXB2, MDSP, MTNT, MFCH, MCOD, W*)
- The blocky arm: cut from a FLUX.2 image generated for this mod.
- The held items and icons: item and block textures from Pixel Perfection CE (see below, CC BY-SA 4.0), scaled up with nearest neighbour,
  composited onto the arm, rotated for the swing frames; the dispenser and TNT cubes are built from the pack's block textures.
  The enchanted crossbow is a purple recolour. Build script: gen/build_weapons.py. These derived sprites are CC BY-SA 4.0.

### Changes we made (CC BY-SA requires stating them; derived textures are CC BY-SA 4.0 too)

All textures: 16x16 tiles upscaled nearest-neighbour x2 to 32x32, made fully opaque (except MCBARS and MCGLASS, binary alpha), renamed.
The build script is gen/build_textures.py; the per-texture source list is gen/texture_sources.txt.

- MCGRASS: grass_block_top recoloured green (it is a biome-tint texture in the pack).
- MCLEAVES: oak_leaves tinted green, transparent holes filled with dark green.
- MCIRON: iron_block levels raised to light grey. MCIDOOR: iron door halves stacked, recoloured to iron grey.
- MCQUARTZ: quartz_block_side brightened. MCENDST: end_stone recoloured pale yellow. MCSEALAN: sea_lantern frame 0, cyan tint. MCICE: ice made opaque.
- MCODOOR / MCIDOOR: top and bottom door halves stacked to 32x64, window holes filled with a dark colour.
- MCWATER1-4: frames 0/4/8/12 of water_still recoloured blue. MCSLIME1-4: the same frames recoloured lime green. MCLAVA1-4: frames 0/4/8/12 of lava_still.
- MCLEVR0 / MCLEVR1: stone_bricks with a cobblestone plate and the lever.png handle composited on top (up = off, down = on with a red glow).

## Credits: pickup and decoration sprites

All the pickup and decoration sprites (100 PNGs in `mod/sprites/`, which override the vanilla Doom sprite names) are
AI-generated for this mod. No downloaded, ripped or Mojang assets were used.

- Model: fal `fal-ai/flux-2` (text to image, 1 MP, $0.012 per image), run through `um fal run`. There were 44 generations
  (about $0.53). The prompts, seeds and request ids are in `gen/items/fal_manifest.jsonl`, and the raw images are in `gen/items/<name>.png`.
- Prompt style: "pixel art game item sprite in the style of 1993 Doom sprites, a blocky Minecraft-like <thing>,
  thick dark outline, three-quarter view, strong shading, single object centered, on a plain flat magenta (#FF00FF)
  background (cyan for the melon and the cake, green for the enchanted apple), no shadow, no glow, no text, no frame".
- Processing: `kits/doom/clean_sprite.py`, then `um sprite fit` (nearest neighbour), then `kits/doom/offsets.py`.
  Local PIL scripts in `gen/items/` (`prep.py`, `post.py`) did the rest:
  - they brightened the iron chestplate (first try) and recoloured the torch flames (red, blue soul fire, green);
  - they shortened the torch poles for the short torches and tilted the arrow bundles;
  - they removed leftover key colour seen through the potion glass;
  - they made the animation frames (sparkles, glint sweeps, a mirrored flame flicker, a brighter barrel flash).
- Hand-pixelled in code (`gen/items/post.py`): ROCKA0 (12x12 TNT block) and BROKA0 (2x2 stack of it). The generated
  TNT cube did not survive being shrunk to 12 px.
- Downloaded assets: none. The CC0 search on OpenGameArt and Kenney could not run because network access was refused in this
  session, so everything was generated.

## Font: mod/fonts/mcfont/ (GZDoom bitmap font folder)

- Source font: **Monocraft** v4.2.1 (`Monocraft.ttf` from `Monocraft-ttf.zip`)
  - URL: https://github.com/IdreesInc/Monocraft (release: https://github.com/IdreesInc/Monocraft/releases/tag/v4.2.1)
  - Author: Idrees Hassan (IdreesInc), Copyright (c) 2022
  - License: SIL Open Font License 1.1 (no Reserved Font Name declared). Full licence text: `mod/fonts/mcfont-OFL.txt` (it must ship with the font).
- What was done: the glyphs U+0021 to U+007E were rendered with PIL at 144 px (16 px per design pixel), sampled at each design-pixel centre to get exact 1-bit glyphs, cropped to their ink width, and given a baked 1 px (63,63,63) drop shadow at +1,+1. This is a modified version (a bitmap derivative) of Monocraft. It is distributed under the OFL 1.1 and is not sold by itself.
- No Mojang font data was used.
